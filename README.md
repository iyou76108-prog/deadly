# Deadly Visuals

Client-side visual customization mod for Minecraft Java Edition 1.21.11 on Fabric.

The project is being built from an empty repository. See the build workflow and source tree for the current implementation.

## Requirements
- Minecraft 1.21.11
- Fabric Loader 0.20.1+
- Fabric API 0.141.6+1.21.11
- Java 21

## Controls
- Right Shift — open the Deadly Visuals menu

## Build
Use Gradle 9.2.1 or newer with JDK 21:
```sh
gradle build
```

The distributable JAR is written to `build/libs/`.
